# ProjetoNascar

Projeto de engenharia de dados para coletar, armazenar e analisar dados em tempo real das corridas da NASCAR, utilizando Python, PostgreSQL, Airflow e dashboards.

## Objetivos

- Coleta de dados via API pública
- Armazenamento em banco PostgreSQL
- Dashboard em Python para visualização em tempo real
- Análise pós-corrida automatizada

## Tecnologias

- Python
- PostgreSQL
- Airflow
- Docker
- Power BI (opcional)
